## [1.12.3] - 2026-04-25

### ColBERT 存储重构与健壮性修复

**概述**: 修复 ColBERT 摘要向量从未成功生成/保存的关键 bug，重构 ColBERT 存储路径结构，并全面消除核心代码中的静默跳过问题。

**ColBERT 存储**:
- 摘要 ColBERT 向量生成改为从 `AbstractIndexManager` 缓存获取摘要文本（而非 chunk metadata），修复 PDF 解析阶段无摘要导致向量永不生成的问题
- ColBERT 向量生成（摘要和正文）改为直接调用 `get_embedding_model()`，不再依赖 `self._retriever` 链路，避免 retriever 未初始化时静默失败
- Chunk ColBERT 存储路径从 `data/` 根目录迁移至 `data/colbert_chunks/`，与 `data/colbert_abstracts/` 对称
- 新增 `ColBERTStorage._chunk_id_to_idx` 字典和 `find_chunk_idx()` 方法，将 chunk_id 查找从 O(N) 线性扫描优化为 O(1)
- `_colbert_rerank_stored` 方法同样改用 `find_chunk_idx()` 替代自建临时字典
- Stage 1.5 摘要 ColBERT rerank 的 `abstract_key` 查找改用 `find_chunk_idx()`

**clear() 修复**:
- `HybridRAGEngine.clear()` 新增摘要 ColBERT 存储清空，修复 `/paper rebuild` 后残留的过期摘要向量
- `clear()` 后正确重置 `self._colbert_storage = None` 和 `self._abstract_colbert_storage = None`
- `clear()` 增加旧路径残留文件清理（`data/colbert_*.npy/bin/json`）
- 未初始化的摘要 ColBERT storage 在 `clear()` 时通过 `shutil.rmtree()` 清理磁盘残留目录

**静默跳过消除**:
- `_get_embedding_model()` 返回 None 时记录 error 日志
- 摘要 ColBERT 向量生成：model 不可用、`get_multi_vector` 返回空、摘要文本为空均有明确 warning/error 日志
- Chunk ColBERT 向量生成：`get_multi_vector` 返回空时记录 warning
- Stage 1.5 摘要 rerank：model 不可用时从 info 提升为 error 日志
- Stage 2 chunk 检索无结果时记录 warning
- `_llm_direct_answer`：provider_manager 不可用、LLM Provider 获取失败、VLM 不可用、响应格式异常均有明确 error/warning
- `_ensure_colbert_storage_initialized`：reranker 为 None 时记录 warning
- `embed_provider.initialize` 无该方法时记录 warning
- CRAG 评分和查询重写的响应格式无法识别时记录 warning
- CLAUDE.md 新增"禁止静默跳过"绝对规则

**其他**:
- 删除 `colbert_storage.py` 中未使用的 `import pickle`
- 更新模块 docstring 中过时的存储路径描述
