# [2.1.1] - 2026-05-15

## 评估管线增强：增量保存、代码溯源与 LLM max_tokens 可配置

本次更新为 Ragas 评估管线添加了三项关键能力：增量保存机制防止中途崩溃丢失结果、git 代码溯源元数据嵌入提升结果可复现性、以及评估 LLM 的 `max_tokens` 参数线程化传递。

---

### 增量保存机制

**核心变更**：将 `evaluate()` 方法中的批量 `asyncio.gather` + 单次文件写入，替换为逐样本 `asyncio.create_task` + `asyncio.Lock` 增量保存。每完成一个样本立即写入 `raw_answers.json`，使得中途崩溃不会丢失已计算的结果。

| 文件 | 变更 |
|------|------|
| `evaluation/ragas_evaluator.py` | `evaluate()` 方法重写：引入 `write_lock = asyncio.Lock()` 保护并发写入；每个样本完成后通过 `process_and_save()` 立即追加到 `raw_answers.json`；`return_exceptions=True` 防止单个样本异常中断整体流程 |
| `evaluation/ragas_evaluator.py` | 新增 `_get_git_info()` 函数：通过 `git rev-parse` / `git log` / `git diff --stat` 提取 commit hash、日期和 dirty 状态，写入 `raw_answers.json` 的 `_metadata` 字段 |

**增量保存输出示例**：
```
[n/total] 已保存到 raw_answers.json
```

---

### raw_answers.json 格式升级

**核心变更**：`raw_answers.json` 输出从裸列表（`[...]`）升级为结构化格式，包含元数据和结果列表。

**旧格式**（仍支持读取）：
```json
[{"question": "...", "answer": "...", ...}, ...]
```

**新格式**：
```json
{
  "_metadata": {
    "generated_at": "2026-05-15T...",
    "git_commit": "abf3a58...",
    "git_commit_date": "2026-05-13 ...",
    "git_dirty": true,
    "total_samples": 50,
    "success_count": 50,
    "llm_model": "gpt-4o-mini",
    "llm_base_url": "...",
    "embedding_model": "text-embedding-v4",
    "embed_base_url": "...",
    "answer_top_k": 5,
    "max_concurrent": 3
  },
  "results": [{"question": "...", ...}, ...]
}
```

| 文件 | 变更 |
|------|------|
| `evaluation/ragas_evaluator.py` | `evaluate()` 输出格式：初始写入含 `_metadata` 的结构化 JSON；每个样本完成后更新 `results` 列表并重写文件 |
| `evaluation/ragas_evaluator.py` | `evaluate_from_raw_answers()` 读取兼容：自动检测旧格式（`list`）和新格式（`dict` with `results` key），旧格式给出 warning 提示重新生成 |
| `evaluation/ragas_evaluator.py` | 文件覆盖保护：写入前检查文件是否已存在，存在时输出 `⚠️` 警告 |

---

### LLM max_tokens 参数线程化

**核心变更**：`eval_llm_max_tokens` 参数从 `RagasEvaluator.__init__()` 向下传递至 `InstructorLLM` 构造，允许用户为推理模型设置更大的 token 限制以容纳 reasoning tokens。默认值 16384。

| 文件 | 变更 |
|------|------|
| `evaluation/ragas_evaluator.py` | `RagasEvaluator.__init__()` 新增 `llm_max_tokens` 参数（默认 16384），存储至 `self._llm_config["max_tokens"]` |
| `evaluation/ragas_evaluator.py` | `_init_llm()` 中将 `max_tokens` 传递给 `InstructorLLM(max_tokens=...)` 构造 |
| `evaluation/run_evaluation_ragas.py` | `run_evaluation()` 新增 `eval_llm_max_tokens` 参数 |
| `evaluation/run_evaluation_ragas.py` | `run_evaluation_from_raw_answers()` 新增 `eval_llm_max_tokens` 参数 |
| `evaluation/run_evaluation_ragas.py` | `run_full_pipeline()` 新增 `eval_llm_max_tokens` 参数，向下透传至 `run_evaluation()` |
| `evaluation/run_evaluation_ragas.py` | CLI `--eval-llm-max-tokens` 参数（`type=int`, default=16384），透传至 `run_evaluation()` 和 `run_evaluation_from_raw_answers()` |
