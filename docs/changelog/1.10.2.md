## [1.10.2] - 2026-04-11

### arXiv 链接提取重构 - OpenAlex API + rapidfuzz 验证链

**文件**: `build_abstract_index.py`

**概述**: 重构 arXiv 链接提取逻辑，使用 OpenAlex API 作为主要数据源，arxiv 库作为 fallback，rapidfuzz 进行标题相似度验证。

**变更**:

1. **OpenAlex API 优先 + arxiv 库 Fallback**
   - 新增 `OpenAlexAPIClient` 类作为主要搜索客户端
   - OpenAlex 提供更稳定的学术论文元数据搜索
   - arxiv 库作为 fallback 方案，确保高可用性
   - 搜索优先级：OpenAlex API -> arxiv 库

2. **rapidfuzz 标题匹配 (50% 阈值)**
   - `find_best_title_match()` 函数使用 `rapidfuzz.fuzz.token_set_ratio` 计算相似度
   - 50% 阈值验证，确保匹配结果可靠
   - 统一 `_normalize()` 和 `find_best_title_match.norm()` 的 LaTeX 处理逻辑

3. **DOI Fallback 机制**
   - 新增 `extract_doi_url()` 方法
   - 当论文无 arXiv ID 但有 DOI 时，提供 DOI 链接
   - 从 DOI URL 中解析 arXiv ID（如 `https://doi.org/10.48550/arxiv.2105.05233`）

4. **LaTeX 标题处理修复**
   - 修复 `$π_0$`, `$π_0.5$`, `$π$`, `π` 等符号的标准化
   - 确保 Greek 字母（π）和 LaTeX 格式（$π$）统一处理
   - 避免因特殊字符导致标题匹配失败

5. **Async 处理修复**
   - `_arxiv_library_fallback()` 使用 `loop.run_in_executor()` 包装阻塞的 arxiv 库调用
   - 避免阻塞事件循环，提升并发性能

6. **标题验证增强**
   - 所有搜索结果均通过 50% 相似度阈值验证
   - 日志输出相似度分数，便于调试和问题排查
   - `--update-links-only` 模式支持仅更新无链接的论文

**技术细节**:
```python
# 搜索优先级
1. OpenAlex API (search_by_title)
   └── rapidfuzz 验证 (token_set_ratio >= 50%)
       └── 提取 arXiv URL 或 DOI

2. arxiv 库 fallback (_arxiv_library_fallback)
   └── rapidfuzz 验证 (token_set_ratio >= 50%)
       └── 提取 arXiv URL
```

**CLI 新增参数**:
- `--no-arxiv-api`: 禁用 arXiv API 查询（当被限流时使用）
