# [2.0.4] - 2026-05-11

## Bug 修复、测试清理与安全加固

本次更新修复了一个 `staticmethod` 调用错误，清理了测试套件中的过期测试和 mock 兼容性问题，并移除了仓库中的硬编码凭证。

---

### Bug 修复

**`rag/paper_link_resolver.py:418` — `NameError: name 'self' is not defined`**

`_extract_identifier_candidates` 是一个 `@staticmethod`，但在内部错误地使用了 `self._strip_identifier_noise()` 进行调用。修复为 `PaperLinkResolver._strip_identifier_noise()`，确保静态方法正确引用类方法。

---

**删除过期测试**：

### 安全修复

**移除硬编码 Neo4j 密码**：

`test_graph_recall_in_search.py`、`test_graph_paper_recall.py`、`test_graph_recall.py`、`test_graph_boost.py` 这 4 个测试文件中硬编码了 Neo4j 连接密码。现已替换为通过共享工具函数读取插件配置：

- 新增 **`test/_test_utils.py::get_neo4j_password()`** — 从 AstrBot 插件配置文件统一读取 Neo4j 密码
- 5 个测试文件（含 `test_graph_rag_integration.py` 已有的 `_get_neo4j_password`）统一改用该共享函数
