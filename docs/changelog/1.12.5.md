## [1.12.5] - 2026-05-04

### Schema 扩展

#### Closed-set 关系类型扩展 (9 → 14)

新增 5 个关系类型：
- `TRAINS_ON`: Model → Dataset used for training
- `IMPLEMENTS`: Model → Code repository providing implementation
- `OUTPERFORMS`: Method → Baseline it significantly exceeds
- `REQUIRES`: Method → Hardware or resource requirement
- `ABLATES_ON`: Method → Component contribution being studied

#### Closed-set 实体类型规范化

- 标准化 9 类实体：`Method, Model, Task, Dataset, Metric, Component, Limitation, Application, Baseline`
- 新增 `RELATION_ALIASES` 和 `ENTITY_TYPE_ALIASES` 映射表

### Grammar 约束修复

- JSON Schema space 规则从 `space ::= " "?` 改为 `space ::= [ \t\n\r]*`，解决 LLM 输出被截断导致空 JSON 问题
- 更新 `triplet_schema.json` 和 `multimodal_schema.json` 使用 JSON Schema（移除废弃的 GBNF 文件）

### Graph Builder 修复

#### 令牌限制调整

- `max_tokens` 从 1024 提升至 4096，解决批量处理时 JSON 输出被截断问题

#### 变量初始化修复

- 修复 `triplets` 变量在 `if not chunks_text` 分支下的初始化问题

#### VLM 响应日志

- 新增 VLM 响应完整日志记录，便于排查 Graph Builder 输出异常

#### JSON 解析简化

- 简化 `_parse_json_response` 方法，移除无用的复杂恢复逻辑

### VLM 优化

- VLM 哈希缓存：进程内缓存，key = SHA256(text)[:12]##SHA256(image_content)[:12]
- 确定性降级：缓存未命中/置信度<0.7 时使用确定性边

### 架构改进

- 删除 `LocalLLMProvider` 类，改用 `LlamaCppVLMProvider` 单例
- Grammar 加载支持 space 规则宽松化

### 测试

- 新增 `test_closed_set_schema.py`：126 个测试覆盖 Schema、规范化、媒体链接等
- 更新测试断言：9 relation types → 14 relation types

### 代码质量

#### 代码审查修复

- **使用公共接口替代内部属性**：将 `graph_store._entity_info` 改为 `graph_store.__contains__`，遵循封装原则
- 全项目静默跳过问题审查通过：所有异常处理均有明确日志记录

### 已知问题说明

- `_process_node` 返回 `None` 为正常行为（文本太短时早期退出，或异常已被 `logger.error` 记录）
- `_docling_subprocess.py` 中的 `pass` 语句为正常设计（可选功能降级，多个 fallback 保证最终结果）
