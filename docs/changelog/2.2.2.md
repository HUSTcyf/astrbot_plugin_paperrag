# [2.2.2] - 2026-05-29

### 知识图谱云端 LLM 支持

- `MultimodalGraphBuilder` 新增 `plugin_config` 参数，通过 `multimodal_provider_id` 配置的云端 LLM Provider（Gemini/GPT 等）进行三元组提取
- 未配置时回退本地 GGUF 模型（`LlamaCppVLMProvider`）
- 云端连续失败 3 次后自动降级到本地模型（`_cloud_consecutive_failures` 断路器），成功调用自动归零
- 降级时通过 `_ensure_local_llm_available()` 懒初始化本地 VLM

### Pydantic 结构化输出验证

- 新增 `Triplet` / `TripletExtraction` / `CrossModalTriplet` / `MultimodalExtraction` / `FigureInfo` Pydantic 模型
- `head_type` / `tail_type` 使用 `Literal[9种封闭实体类型]` 约束
- `relation_type` 使用 `Literal[14种关系类型]` 约束
- `confidence` 范围 `[0.0, 1.0]`，`head` / `tail` 最大 60 字符
- 单条三元组验证失败不影响其余（逐条 `model_validate` + `try/except`），JSON 截断恢复后重试 Pydantic
- 废弃 `_extract_triplets` / `_try_truncate_recover` 实例方法，提取为模块级 `_strip_code_block()` / `_try_parse_json()` / `_try_truncate_recover()`

### 后台构建进度推送

- `_graph_build_background_task` 中 `send_msg()` 通过 `context.send_message(session, MessageChain)` 实时推送进度到用户聊天窗口
- 每篇论文完成时显示累计实体数和三元组数
- 推送失败非致命，不中断构建流程

### 修复

- Grammar 警告误报：云端 Provider 路径加入 `self._cloud_llm is None` 守卫
- Token 预算检查：云端路径跳过 `n_ctx` 限制
- `_validate_triplet_response` 空列表不再判为失败
- `CrossModalTriplet.tail_type` Pydantic 约束修复
- 版本号 2.2.1 → 2.2.2
