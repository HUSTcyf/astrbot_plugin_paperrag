# [2.2.0] - 2026-05-25

## 新增 LLM Tool：paper_search 与 code_execute

本次更新为插件新增了两个 LLM Tool（paper_search、code_execute），使 AstrBot 的 LLM 可以调用的 paperrag 工具总数达到 4 个。同时修复了 `@register()` 装饰器中遗留的旧版本号（1.12.6 → 2.2.0），并新增了远程控制 Claude Code 的架构规划文档。

---

## 一、新 LLM Tool 注册

### 1.1 `paper_search` — 轻量混合 RAG 检索

在 `main.py` 的 `__init__` 中注册新的 `paper_search` LLM Tool。与 `paper_arag`（静态 DAG Agentic RAG）和 `paper_react`（ReAct Agent 动态工具选择）相比，`paper_search` 更轻量快速，内部调用链为 `engine.search` → 文本清洗 → LLM 生成回答，适合简单的论文内容查询。

| 参数 | 类型 | 说明 |
|------|------|------|
| `query` | string | 论文检索查询，从本地论文库中搜索相关内容 |
| `top_k` | integer | 召回数，默认 5 |

**调用链**：`_paper_search_tool()` → `engine.search(query, top_k)` → `_clean_search_results()` → `_generate_answer_from_results()`

### 1.2 `code_execute` — Claude Code 编程执行器

在 `main.py` 的 `__init__` 中注册新的 `code_execute` LLM Tool。通过 `claude -p` 子进程启动 Claude Code 执行编程任务（写/改代码、调试、运行实验、重构、git 操作等）。推荐使用模式：Agent 先通过 `paper_search`/`paper_arag`/`paper_react` 检索相关知识并整合上下文，然后将完整的任务描述传递给此工具。

| 参数 | 类型 | 说明 |
|------|------|------|
| `task` | string | 完整的编程任务描述，需包含所有必要上下文和指令 |
| `timeout` | integer | 最大执行秒数，默认 300 |

**调用链**：`_code_execute_tool()` → `subprocess.Popen(["claude", "-p", task])` → 捕获 stdout/stderr → 返回结果

| 文件 | 变更 |
|------|------|
| `main.py` | `__init__` 中新增 `paper_search` 和 `code_execute` 两个 `context.register_llm_tool()` 调用 |
| `commands/paper.py` | 新增 `_paper_search_tool()` 和 `_code_execute_tool()` 两个 async 方法 |

## 二、插件 LLM Tool 全景

当前插件共注册 4 个 LLM Tool，覆盖从轻量检索到代码执行的全链路：

| # | Tool 名称 | 类型 | 说明 |
|---|-----------|------|------|
| 1 | `paper_arag` | 静态 DAG Agentic RAG | 多跳推理、对比分析、引用溯源 |
| 2 | `paper_react` | ReAct Agent | 自主选择检索工具（向量/知识图谱） |
| 3 | `paper_search` | **新增** 轻量混合 RAG | 直接搜索 + 文本清洗 + LLM 回答，适合简单查询 |
| 4 | `code_execute` | **新增** Claude Code 执行器 | `claude -p` 子进程执行编程任务 |
