## 一、飞书文档导出管线

### 1.1 图片定位：Sentinel 标记法 + 双锚点

LLM 在相关工作/方法论章节末尾放置 `[PAPER_FIGURES]` sentinel，代码通过 `str.find()` 精确替换。正则仅作为 sentinel 缺失时的回退。

**4 层优先级**：Sentinel 精确匹配 → 正则匹配章节末尾（支持中文数字标题 `一、相关工作`） → 回退到方法论/实验章节之前 → 兜底追加到末尾。

**双锚点**：引用图表 → 相关工作末尾，方法论图表 → 方法论末尾。

**关键修复**：Sentinel 无图表时自动清除防止泄露；连续图片仅第一张有 anchor 的 bug 通过 `_last_anchor` 回退修复；`_extract_inline_images` 路径解码先尝试原始路径再解码。

| 文件 | 变更 |
|------|------|
| `idea/markdown.py` | `_append_figure_section` 重写为 4 层策略；中文数字标题支持；双锚点返回 |
| `idea/feishu_doc.py` | `_last_anchor` 回退；`_clean_figure_references` 改为逐字符扫描；临时文件清理 |
| `idea/generation.py` | Plan A prompt 插入 `[PAPER_FIGURES]` sentinel 指令 |
| `idea/test/test_image_pipeline.py` | +9 测试覆盖 sentinel 替换、regex 回退、泄露防护 |

### 1.2 规范化章节体系

定义 8 个规范化章节标题，LLM prompt 强制精确格式。彻底移除 `_find_figure_anchor` 和 `_clean_figure_references` 中的正则，改用 `str.find()` + 逐字符扫描。`create_feishu_document` 从 `clean_text` 重算锚点。所有 prompt 移除加粗要求。

| 文件 | 变更 |
|------|------|
| `idea/markdown.py` | 新增 `CANONICAL_SECTIONS`、`_normalize_section_headings()`、`_find_section_anchor()` |
| `idea/feishu_doc.py` | 重写 `_clean_figure_references()`；替换 `__import__('re')` 为模块级 `import re` |
| `idea/generation.py` | Prompt 规范化章节标题、移除加粗 |

### 1.3 Token 预算管理 + 云端 LLM 优化

长引用上下文支持分批 token 预算管理：`count_tokens()` 计算 n_ctx 余量，超长自动分批→分摘要→合并。Plan B 优先使用云端 LLM 跳过分批。VLM 调用通过 `_compute_vlm_max_tokens()` 动态计算输出预算（下限 1024）。

涉及 6 个文件移除硬编码 `max_tokens`：`agentic_rag/knowledge_extractor.py`、`rag/hybrid_rag.py`、`rag/abstract_index.py` 等。

### 1.4 其他修复

`_extract_image_paths()` 增加 `![` 和 `]` 精确配对；`_append_figure_section()` 同时输出 figures 和 tables；`multimodal_extractor` 保证 captions 目录存在。

## 四、参考文献处理

### 4.1 存储架构重构：cited_ref_ids + paper_doc_stats.json

chunk metadata 从存储完整引用对象改为仅存 `cited_ref_ids` 列表。完整详情保存在 `data/paper_doc_stats.json`，召回时通过 `file_name` + `ref_id` 查找。

```
_enrich_references → _save_paper_doc_stats → paper_doc_stats.json
                   → link_citations_to_references → chunk.metadata['cited_ref_ids']
                   → insert_nodes → Milvus（只存 id 列表）
```

### 4.2 多源链接全保存 + /paper refstats 纯 JSON 统计

修复 `_enrich_references` 只保存 `doi_url` 的 bug，现在 `arxiv_url` 也保存。URL 回退链：`doi → arxiv_url → ""`。删除 ~80 行死代码（`_enrich_from_arxiv()`）。

`/paper refstats` 改为从 `paper_doc_stats.json` 直接聚合，完全跳过 Milvus 查询。统计规则：每篇论文同一参考文献只计一次，按标题归一化后跨论文聚合。新增 `compute_refstats()` 和 `get_papers_with_zero_refs_from_json()` 两个独立函数，`get_all_references()` 和 `get_papers_with_zero_references()` 从 ~85 行缩至 ~10 行委托调用。

| 文件 | 变更 |
|------|------|
| `rag/reference_processor.py` | `Reference` 新增 `ref_arxiv_url`；`cited_ref_ids` 存储；新增 `compute_refstats()`、`get_papers_with_zero_refs_from_json()`；删除 `_enrich_from_arxiv()`；key 格式统一为 `.name` |
| `rag/hybrid_index.py` | `get_all_references()` 和 `get_papers_with_zero_references()` 改为纯 JSON 委托；合并写入 paper_doc_stats.json |
| `idea/generation.py` | `_build_verified_reference_index()` 从 JSON 查找；URL 回退链 |
| `commands/paper.py` | rebuild 清理 `paper_doc_stats.json`；`_paper_refstats` 显示标签更新 |
