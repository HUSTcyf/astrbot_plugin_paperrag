# [2.2.3] - 2026-06-03

### 远程 SSH Claude Code 执行

- 新增 `commands/remote_code.py`，实现 `RemoteCodeMixin` 类，通过 SSH（paramiko）连接远程主机执行 Claude Code 编程任务
- 新增 `/cc` 命令组，包含以下子命令：
  - `/cc status` -- 查看远程连接状态
  - `/cc connect <host>` -- 建立远程 SSH 连接
  - `/cc install <package>` -- 在远程主机安装 Python 包
  - `/cc exec <command>` -- 在远程主机执行任意命令
  - `/cc config` -- 查看当前远程执行配置
- 全部用户交互字符串使用中文本地化

### 双后端代码执行架构

- `_code_execute_tool` 重构为调度器，根据 `remote_exec.enabled` 配置决定走远程 SSH 还是本地后端
- 新增 `_conf_schema.json` 中 `remote_exec` 配置段落（`enabled`、`hostname`、`port`、`username`、`key_filename`、`timeout`）
- 新增 `paramiko>=3.4.0` 依赖至 `requirements.txt`

### 涉及文件

- `commands/remote_code.py` -- 新增，远程 SSH Claude Code 执行实现
- `commands/base.py` -- `_code_execute_tool` 重构为远程/本地调度器
- `_conf_schema.json` -- 新增 `remote_exec` 配置段落
- `requirements.txt` -- 新增 `paramiko>=3.4.0`
