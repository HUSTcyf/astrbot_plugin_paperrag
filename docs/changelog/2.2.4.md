# [2.2.4] - 2026-06-09

### Academic Intent Guard for LLM Tools

- 新增 `commands/base.py` 中 `_guard_academic_intent()` 方法，对 `_paper_search_tool`、`_agentic_rag_tool` 和 `_react_rag_tool` 执行非学术查询预检查
- 非学术查询（问候语、闲聊）在进入 RAG 流水线前被拒绝，每次节省约 30+ 秒和 LLM tokens 消耗

### 强化学术意图检测

- `commands/base.py` 中 `_check_academic_intent` 负面检测扩展至覆盖 "不"、"no"、"非" 及其常见变体
- 添加 LLM 返回不可识别响应时的 `logger.warning()` 日志

### 强化 LLM Tool 描述

- `main.py` 中 `paper_search`、`paper_arag`、`paper_react` 工具描述添加 `【严格限制】` 前缀，阻止主 LLM 为非学术查询调用论文工具

### Cypher Code Fence 修复

- `graphrag/graph_rag_engine.py` 中 `_make_cypher_validator` 新增 markdown code fence 剥离步骤
- `TextToCypherRetriever` (llama_index) 有时返回 ` ```cypher ... ``` ` 包裹的 Cypher，validator 现在自动 strip 后再校验首 token

### 涉及文件

- `commands/base.py` -- 新增 `_guard_academic_intent()`，强化 `_check_academic_intent`
- `commands/paper.py` -- 三个 LLM Tool 入口集成 `_guard_academic_intent()` 预检查
- `main.py` -- LLM Tool 描述添加 `【严格限制】` 前缀，版本号 2.2.4
- `graphrag/graph_rag_engine.py` -- Cypher validator 新增 code fence 剥离
- `metadata.yaml` -- version 2.2.4
- `README.md` -- v2.2.4 变更说明 + 近期更新整合
