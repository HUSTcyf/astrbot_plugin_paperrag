# [2.2.5] - 2026-08-10

### 微调 LoRA 模型接入（FinetuneLLMProvider）

- 新增 `provider/finetune_llm_provider.py`：transformers+peft 直连的本地微调模型推理 provider，
  惰性加载、异步 chat 不阻塞事件循环。废弃的 llama-cpp GGUF LoRA 死代码已回滚。
- `_conf_schema.json` + `rag/rag_engine.py: RAGConfig` 新增 4 个配置键（两处同步）：
  `finetune_llm_enabled`、`finetune_base_model_dir`、`finetune_adapter_dir`、`finetune_llm_max_new_tokens`、
  `finetune_llm_num_threads`。
- `commands/base.py` 新增 lazy 单例 `_get_finetune_llm()`（仅 `finetune_llm_enabled=true` 时实例化）。
- 微调模型仅作评测对比对象，不作为生产默认生成器。

### RAGAS 评测 MiniMax 兼容层

- 新增 `evaluation/minimax_compat.py`：集中 MiniMax-M3 三处差异（思考模式 `<think>` 块、
  非标准 `/v1/embeddings` 格式、`embo-01` 模型名），智谱等标准端点不受影响。
- `ragas_generator.py` / `ragas_evaluator.py` 统一经 `minimax_compat` 注入 thinking disabled
  与 embedding 请求/响应适配。
- 429 限流长退避：`RateLimitError` + Retry-After 解析 + 指数退避（默认 `max_rpm=30`）。
- `_normalize_json_response`：剥离 `<think>` / markdown code fence / 双重 JSON 包装、
  空对象判错、schema 回显检测。

### 测试集生成容错

- transforms 阶段 7 个 extractor（Summary/Headlines/Themes/NER/Embedding/CustomNodeFilter/HeadlineSplitter）
  逐个 try/except，单节点失败不再中止整个管线（绕过 ragas `run_async_tasks` 无条件 raise）。
- `Executor.results` 过滤混入结果的 Exception，修复"单样本失败 → 全量 0 样本"。

### 其他修复

- `embedding/unsloth_embedding.py`：unsloth `ImportError` 时回退 transformers 直连（AMD ROCm 环境）。
- `provider/llama_cpp_vlm.py`：mmproj 加载重构为 MTMDChatHandler（0.3.34 起 mmproj 被静默忽略）。
- `rag/hybrid_parser.py`：docling 惰性导入，检索/评测路径不再强依赖。
- `provider/llm_utils.py`：`extract_text_from_response` 兼容 AstrBot `completion_text`。
- `test/test_main_split.py`：断言补上 v2.2.3 新增的 `cc` 命令组。
